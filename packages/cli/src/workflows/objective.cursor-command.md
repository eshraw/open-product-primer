Create a new objective (OKR) in `oprim/objectives/`. Scan for `OBJ-(\d+)-` to assign next ID (zero-padded, default 001; never reuse IDs). Read `oprim/config.yaml`'s `rules.objective` — if non-empty, apply it as additional guidance and reflect it in the generated content; if empty, behavior is unchanged. Gather: title (an outcome, not a project), period (e.g. `2027-Q1`), 2–4 key results (`metric: baseline → target by end of period`), rationale. Ask if superseding an existing objective. If `oprim/templates/objective.md` begins with a frontmatter block, prepend frontmatter with `type: objective`, `title`, `description`, `tags`, `timestamp`, `period` and `status: Active`; otherwise write no frontmatter. Write `oprim/objectives/OBJ-NNN-<slug>.md` with `# OBJ-NNN: <title>` and sections `## Status` (`Active`), `## Period`, `## Key results`, `## Rationale`. If superseding: update the old objective's Status to "Superseded by OBJ-NNN". Report what was created and that bets link it with `- Objectives: OBJ-NNN` in `## Links`.
