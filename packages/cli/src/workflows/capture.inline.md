### Inbox capture (oprim-capture)
Append one item to `inbox.md` — no follow-up questions, no routing (that is `oprim-triage`).

1. Use the text given; only if none was given, ask once what to capture.
2. Append `- [ ] <YYYY-MM-DD HH:MM> <text>` (current local time, text on one line) to the end of `inbox.md`; create the file with a `# Inbox` heading if missing. Never edit existing lines.
3. Reply with the appended line only.
